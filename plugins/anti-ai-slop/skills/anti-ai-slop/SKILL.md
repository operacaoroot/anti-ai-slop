# Anti-AI Slop — Guia de Padrões Proibidos (PT-BR)

Esta skill existe para que nenhum texto em português saia com "cheiro de IA" — construções desgastadas, hipérboles vazias, generalizações sem dado, tom de coach motivacional. Aplica-se a qualquer formato: post, artigo, e-mail, roteiro, relatório, legenda, anúncio, descrição de produto, mensagem institucional, etc.

**Regra de uso:** verificar TODO o texto antes de entregar o resultado final, bloco por bloco (parágrafo, frase, seção). Se qualquer padrão proibido abaixo aparecer: **reescrever, nunca apenas ajustar**.

---

## 1. Construções diretas proibidas

| Proibido | Por quê | Alternativa |
|---|---|---|
| "Não é X, é Y" | Construção desgastada, soa formulaica | Mostrar a diferença sem nomear a fórmula |
| "E isso muda tudo" | Hipérbole vazia, não prova nada | Dizer especificamente o que muda e como |
| "No fim das contas" | Transição de fechamento genérica | Cortar ou reescrever a ideia sem transição |
| "Ao final do dia" | Anglicismo desgastado | Cortar |
| "A pergunta fica:" | Encerramento fraco, não cria tensão | Formular a pergunta sem anunciá-la |
| "De forma X" | Vaga, preenche espaço sem informar | Ser específico sobre como |
| "Claro/clara" genérico | "É claro que X" — padding | Cortar o "é claro que" |
| "Cada vez mais" | Lugar-comum sem dado | Usar o dado real em vez da sensação |
| "Em um mundo onde" | Abertura de redação escolar | Começar direto no fato |
| "Vivemos em uma era" | Idem | Idem |
| "É preciso" / "Devemos" | Tom de coach, 2ª pessoa implícita | Tom jornalístico — descrever, não prescrever |
| "Você precisa" / "Você deve" | 2ª pessoa impositiva — evitar fora de instruções diretas | Reescrever como reportagem, salvo quando o formato exige instrução literal (ex: passo a passo técnico) |
| "Simplesmente" | Minimiza sem informar | Cortar |
| "Basicamente" | Hedge desnecessário | Cortar |
| "Na prática" (como abertura) | Transição preguiçosa | Ir direto para a prática |

## 2. Paralelismos forçados (proibidos)

- "X diminui, Y acelera"
- "Enquanto X perde, Y ganha"
- "Menos X, mais Y"
- "Antes: X. Agora: Y."

> Quando o contraste for real e necessário, escrever em prosa com conector natural — nunca em fórmula de dois pontos.

## 3. Títulos e ganchos proibidos

Vale para manchete, título de artigo, assunto de e-mail, primeira frase de post, nome de seção — qualquer texto que tenha a função de abrir ou introduzir.

- "Quando X vira Y"
- "A ascensão de X"
- "O impacto de X"
- "Por que X está mudando Y"
- "X: o que você precisa saber"
- "Tudo que você precisa saber sobre X"
- "O guia definitivo de X"
- "X mudou para sempre"
- "Virou" como verbo principal de título (ex: "o mercado virou")
- "Revelamos" / "Descobrimos" / "Mostramos"
- Qualquer título abrindo com "descubra", "saiba", "conheça"

## 4. Teste do tom de IA

Ler o texto em voz alta. Se a resposta for **"sim"** para qualquer pergunta abaixo, reescrever:

1. Qualquer página do Instagram com mais de 10k seguidores poderia ter escrito isso?
2. O texto funcionaria para qualquer assunto/nicho sem trocar uma palavra?
3. Tem frase que soa como conclusão de redação do ENEM?
4. Tem alguma palavra que nenhum jornalista do Estadão usaria?
5. O texto motiva ou enche linguiça sem informar nada concreto?

> Se sim para qualquer uma → reescrever com dado específico, ângulo concreto ou tensão real.

## 5. Estrutura — aberturas e fechamentos

**Abertura de texto proibida** (vale para o primeiro parágrafo de qualquer formato — artigo, post, e-mail, roteiro):

- "Hoje vamos falar sobre..."
- "Neste texto/artigo/vídeo você vai aprender..."
- "Antes de começar..."
- "Como você provavelmente sabe..."
- "Muitas pessoas perguntam..."
- "Todo mundo já ouviu falar de..."

> O texto começa no fato, na tensão ou no dado — nunca na preparação ou no aviso do que vem a seguir.

**Fechamento de seção/parágrafo proibido** (transições entre partes de um texto maior):

- "Continue lendo para saber mais →"
- "Mas tem mais..."
- "Não para por aí"
- "E não é só isso"

> A próxima parte deve ser inevitável pela tensão narrativa — não pelo aviso explícito de que "vem mais coisa".

**Fechamento de chamada para ação (CTA) proibido:**

- "Espero que tenha gostado!"
- "Se tiver dúvidas, me manda mensagem"
- "Obrigado por acompanhar/ler"
- "Não esqueça de seguir/se inscrever"
- "Se esse conteúdo te ajudou..."

> CTA é diretivo, não cordial. Diz a ação esperada e o que ela gera. Sem agradecimento nem súplica.

## 6. Dados e fontes

- "Estudos mostram que..." → sempre nomear o estudo
- "Especialistas dizem..." → sempre nomear quem
- "Muitas empresas..." → sempre dar número ou exemplo
- "A maioria das pessoas..." → sempre dar percentual
- "Recentemente..." → sempre dar data ou período
- "No Brasil..." → sempre dar dado específico do Brasil

> **Regra:** número + fonte + ano. Sem os três, não é dado — é opinião.

## 7. Vocabulário — jargões a evitar

| Jargão | Substituir por |
|---|---|
| "Ecossistema" | sistema, mercado, ambiente |
| "Sinergia" | integração, colaboração |
| "Disruptivo" | que quebra com o padrão, que muda o jogo |
| "Stakeholders" | envolvidos, partes interessadas |
| "Mindset" | mentalidade, modo de pensar |
| "Engajamento" (no sentido de "fazer bem") | resultado, performance, alcance |
| "Curadoria" (genérico) | seleção, escolha criteriosa |
| "Storytelling" | narrativa, história |
| "Overview" | visão geral, panorama |
| "Benchmark" (como verbo) | comparar com referências, medir contra o mercado |

> **Exceção:** se o jargão é parte da identidade do nicho (ex: "CAC" em marketing de performance, "SLA" em operações), pode manter — mas explicar na primeira ocorrência.

## 8. Regras gramaticais obrigatórias

- Artigos sempre presentes — nunca omitir um/uma/o/a para economizar espaço.
- Conectivos naturais em cada bloco — porque, só que, por isso, enquanto, quando, mas, aí, então.
- Cada parágrafo soa como texto de reportagem — não como lista disfarçada de frase solta.
- Nunca cortar conectivo para caber em um limite de espaço/caracteres — reescrever a ideia completa, só que menor.

## Checklist final (rodar em todo texto antes de entregar)

- [ ] Tem dado específico com fonte quando faz afirmação factual?
- [ ] Não usa nenhuma construção da lista proibida (seções 1–3)?
- [ ] Passa no teste do tom de IA (seção 4)?
- [ ] Cada parágrafo/bloco tem conectivo natural?
- [ ] Artigos presentes em todas as frases?
- [ ] Abertura do texto vai direto ao fato, tensão ou dado?
- [ ] Transições entre partes abrem espaço para o que vem a seguir sem anunciar explicitamente?
- [ ] CTA (quando houver) é diretivo, sem agradecimento?

Se qualquer item falhar, voltar ao trecho e reescrever — não apenas trocar uma palavra isolada. O objetivo é que o texto inteiro funcione em prosa natural, com tensão e especificidade reais, não que passe raspando na checklist.
